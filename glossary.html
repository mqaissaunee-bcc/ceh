74 terms shown

A

AES
Advanced Encryption Standard — the modern symmetric cipher, typically with 128- or 256-bit keys. Cryptography ↗
Arp spoofing
Sending forged ARP messages to associate the attacker's MAC with another host's IP, enabling interception. Sniffing ↗
Asymmetric encryption
Public-key cryptography using a linked key pair — a public key to encrypt/verify and a private key to decrypt/sign. Cryptography ↗
Attack surface
The total set of points where an attacker could try to enter or extract data from a system. Introduction to Ethical Hacking ↗
Availability
Ensuring systems and data are accessible to authorized users when needed. Denial-of-Service ↗

B

Botnet
A network of compromised devices controlled by an attacker, often used to launch DDoS attacks. Denial-of-Service ↗

C

C2
Command and Control — the infrastructure an attacker uses to remotely direct compromised systems. Malware Threats ↗
CIA Triad
Confidentiality, Integrity, and Availability — the three core goals of information security. Introduction to Ethical Hacking ↗
Confidentiality
Ensuring information is readable only by authorized parties, typically via encryption. Cryptography ↗
Container escape
An attack that breaks out of a container's isolation to reach the host or other containers. Cloud Computing ↗
CSRF
Cross-Site Request Forgery — tricking a logged-in user's browser into making an unwanted authenticated request. Hacking Web Applications ↗
CVE
Common Vulnerabilities and Exposures — a public catalog assigning a unique ID to each known vulnerability. Vulnerability Analysis ↗

D

DDOS
Distributed Denial of Service — overwhelming a target with traffic from many sources to make it unavailable. Denial-of-Service ↗
Deauth
A forged Wi-Fi management frame that disconnects a client, often to force a reconnection that yields a handshake. Hacking Wireless Networks ↗
Defense in depth
Layering multiple independent security controls so that if one fails, others still protect the system. Introduction to Ethical Hacking ↗
Digital signature
Data signed with a private key that anyone can verify with the matching public key, proving origin and integrity. Cryptography ↗
Directory traversal
An attack that uses ../ sequences to access files outside the web server's intended directory. Hacking Web Servers ↗

E

ECC
Elliptic Curve Cryptography — asymmetric cryptography giving RSA-level security with much smaller keys. Cryptography ↗
Enumeration
Actively extracting detailed information — usernames, shares, services — from a target's systems. Enumeration ↗
Evil twin
A rogue access point impersonating a legitimate network's name to lure victims into connecting. Hacking Wireless Networks ↗
Exploit
Code or a technique that takes advantage of a specific vulnerability to cause unintended behavior. Vulnerability Analysis ↗

H

Harvest now, decrypt later
Recording encrypted traffic today to decrypt once quantum computers mature; needs no quantum capability at collection time. Cryptography ↗
Hashing
A one-way function mapping any input to a fixed-size digest; used for integrity checks and password storage. Cryptography ↗

I

IAM
Identity and Access Management — the cloud system governing who can do what to which resources. Cloud Computing ↗
IDOR
Insecure Direct Object Reference — changing a reference (like an ID) to access another user's data. Hacking Web Applications ↗
IDS
Intrusion Detection System — monitors network or host activity and alerts on suspected malicious behavior. Evading IDS, Firewalls, and Honeypots ↗
Injection
A flaw where untrusted input is sent to an interpreter as part of a command or query and executed as code. Hacking Web Applications ↗
Integrity
Ensuring data has not been altered; tampering can be detected, typically via hashing. Cryptography ↗
IPS
Intrusion Prevention System — like an IDS but able to actively block detected malicious traffic. Evading IDS, Firewalls, and Honeypots ↗

J

Jailbreaking
Gaining privileged administrative control of an iOS device by removing Apple's restrictions. Hacking Mobile Platforms ↗

L

Lateral movement
Moving from one compromised system to others inside a network to reach higher-value targets. System Hacking ↗
Least privilege
Granting every identity only the permissions it needs and no more, to limit the blast radius of a compromise. Cloud Computing ↗

M

Malware
Malicious software designed to damage, disrupt, or gain unauthorized access to systems. Malware Threats ↗
Man-in-the-middle
An attacker who secretly relays and possibly alters communication between two parties who believe they talk directly. Sniffing ↗
MDM
Mobile Device Management — software for centrally securing and enforcing policy on an organization's mobile devices. Hacking Mobile Platforms ↗
MFA
Multi-Factor Authentication — requiring two or more independent proofs of identity to log in. System Hacking ↗

N

Non-repudiation
A guarantee that a party cannot credibly deny having taken an action, e.g. signing a message. Cryptography ↗

O

OWASP
Open Web Application Security Project — a nonprofit best known for its Top 10 lists of critical security risks. Hacking Web Applications ↗

P

Parameterized query
A query that sends SQL code and user data on separate channels so input can never be parsed as code — the definitive SQLi fix. SQL Injection ↗
Payload
The part of an attack that performs the intended malicious action once delivered. Malware Threats ↗
Phishing
Fraudulent messages that impersonate a trusted source to steal credentials or deliver malware. Social Engineering ↗
PKI
Public Key Infrastructure — the system of certificates and authorities that binds public keys to verified identities. Cryptography ↗
PLC
Programmable Logic Controller — a rugged computer that directly controls physical industrial machinery. IoT and OT Hacking ↗
Post-quantum cryptography
New algorithms (e.g. ML-KEM, ML-DSA) designed to resist attacks from quantum computers. Cryptography ↗
Pretexting
Inventing a fabricated scenario or identity to persuade a victim to divulge information or act. Social Engineering ↗
Privilege escalation
Gaining higher permissions than intended — vertically (to a higher role) or horizontally (to another user's resources). System Hacking ↗

R

Rainbow table
A precomputed table of hashes used to reverse unsalted password hashes quickly. System Hacking ↗
Ransomware
Malware that encrypts a victim's data and demands payment for the decryption key. Malware Threats ↗
Reconnaissance
The first phase of an attack: gathering information about a target before attempting to breach it. Footprinting and Reconnaissance ↗
Rooting
Gaining privileged administrative control of an Android device by removing manufacturer restrictions. Hacking Mobile Platforms ↗
Rootkit
Malware that hides its presence and maintains privileged access deep in a system. Malware Threats ↗
RSA
A widely used asymmetric algorithm whose security rests on the difficulty of factoring large numbers. Cryptography ↗

S

Salt
A unique random value added to a password before hashing, defeating precomputed (rainbow-table) attacks. Cryptography ↗
Sandbox
An isolated environment where an app runs without free access to other apps or the system. Hacking Mobile Platforms ↗
SCADA
Supervisory Control and Data Acquisition — systems that monitor and control industrial processes. IoT and OT Hacking ↗
Session hijacking
Taking over a valid user session, typically by stealing or forging the session token. Session Hijacking ↗
Shared responsibility model
The split where the cloud provider secures the infrastructure and the customer secures their data, configuration, and access. Cloud Computing ↗
SIEM
Security Information and Event Management — a system that aggregates and correlates logs to detect threats. Evading IDS, Firewalls, and Honeypots ↗
Smishing
Phishing carried out over SMS text messages, often with malicious links. Hacking Mobile Platforms ↗
Social engineering
Manipulating people into revealing information or taking actions that compromise security. Social Engineering ↗
SQL Injection
Injecting attacker-controlled SQL into a query so the database executes it as code rather than data. SQL Injection ↗
Symmetric encryption
Encryption using one shared secret key for both encryption and decryption; fast, ideal for bulk data (e.g. AES). Cryptography ↗

T

Threat actor
Any individual or group that carries out, or intends to carry out, malicious activity. Introduction to Ethical Hacking ↗
TLS
Transport Layer Security — the protocol behind HTTPS; uses asymmetric crypto to exchange a fast symmetric session key. Cryptography ↗
Trojan
Malware disguised as legitimate software to trick a user into installing it. Malware Threats ↗

V

Vishing
Voice phishing — social engineering conducted over a phone call. Social Engineering ↗
Vulnerability
A weakness in a system that an attacker can use to compromise its security. Vulnerability Analysis ↗

W

WAF
Web Application Firewall — filters malicious HTTP requests; a layer of defense, not a substitute for fixing code. Hacking Web Servers ↗
Web shell
A malicious script uploaded to a server that gives an attacker remote command execution. Hacking Web Applications ↗
WPA2
A long-standing Wi-Fi security standard using strong AES encryption; vulnerable when the passphrase is weak. Hacking Wireless Networks ↗
WPA3
The current Wi-Fi security standard, whose SAE handshake resists the offline dictionary attacks that defeat WPA2-PSK. Hacking Wireless Networks ↗

X

XSS
Cross-Site Scripting — injecting malicious script into a page so it runs in other users' browsers. Hacking Web Applications ↗

Z

Zero trust
“Never trust, always verify” — a model that treats every request as untrusted regardless of origin and continuously verifies identity and authorization. Cloud Computing ↗
Zero-day
A vulnerability unknown to the vendor, with no patch available, that attackers can exploit before it is fixed. Vulnerability Analysis ↗
