Commands & examples

site:example.com              # restrict results to a single domain
site:example.com filetype:pdf # find PDF files on that domain
site:example.com inurl:admin  # find URLs containing "admin" (login pages)
intitle:"index of"            # find open directory listings
site:example.com ext:sql      # find exposed database dumps
cache:example.com             # view a cached copy of a page
# Look up domain registration details
whois example.com

# Look up who owns an IP address / netblock
whois 203.0.113.10
# Query all common records for a domain
dig example.com ANY +noall +answer

# Specific record types
dig example.com MX      # mail servers
dig example.com NS      # name servers
dig example.com TXT     # SPF/DKIM and other text records
nslookup -type=A mail.example.com   # resolve a hostname to an IP
# Attempt a zone transfer against a name server
dig axfr example.com @ns1.example.com

Key terms

Attack surface
The total set of points where an attacker could try to enter or extract data from a system.
Enumeration
Actively extracting detailed information — usernames, shares, services — from a target's systems.
IPS
Intrusion Prevention System — like an IDS but able to actively block detected malicious traffic.
Phishing
Fraudulent messages that impersonate a trusted source to steal credentials or deliver malware.
Reconnaissance
The first phase of an attack: gathering information about a target before attempting to breach it.
Salt
A unique random value added to a password before hashing, defeating precomputed (rainbow-table) attacks.
Social engineering
Manipulating people into revealing information or taking actions that compromise security.
